═══════════════════════════════════════
  v67suite — GitHub Auto-Build
  Sigue estos pasos y GitHub te da el .exe
═══════════════════════════════════════

PASO 1 — Crear cuenta en GitHub (si no tenés)
──────────────────────────────────────────────
  Ir a: https://github.com
  Sign up → crear cuenta gratis

PASO 2 — Crear repositorio nuevo
──────────────────────────────────────────────
  1. Click en "+" arriba a la derecha
  2. "New repository"
  3. Nombre: v67suite  (o cualquier nombre)
  4. Seleccionar: Private  ← IMPORTANTE
  5. Click "Create repository"

PASO 3 — Subir los archivos
──────────────────────────────────────────────
  En la página del repo vacío:
  1. Click "uploading an existing file"
  2. Arrastrar TODOS los archivos de esta carpeta
     incluyendo la carpeta .github/ completa
     (en Windows puede que esté oculta —
      activar "mostrar archivos ocultos" en el
      Explorador de archivos)
  3. Click "Commit changes"

PASO 4 — Esperar el build (2-3 minutos)
──────────────────────────────────────────────
  1. Ir a la pestaña "Actions" del repo
  2. Ver el workflow "Build v67suite" corriendo
  3. Esperar que el circulo se ponga verde ✓

PASO 5 — Bajar el .exe
──────────────────────────────────────────────
  1. Click en el workflow completado
  2. Bajar hasta "Artifacts"
  3. Click en "v67suite-exe"
  4. Se baja un .zip con el v67suite.exe adentro

PASO 6 — Usar
──────────────────────────────────────────────
  1. Abrir Roblox → entrar a un juego
  2. Click derecho en v67suite.exe
     → "Ejecutar como administrador"
  3. RMB (clic derecho) mantenido = Aimbot
  4. ESP rojo aparece automático sobre todos

═══════════════════════════════════════
NOTAS
═══════════════════════════════════════
  - Si el .exe no conecta con Roblox:
    Los offsets cambian con updates de Roblox.
    Avisame y te doy los offsets nuevos.

  - Si Windows Defender lo borra:
    Click derecho en la carpeta del .exe
    → Propiedades → Desbloquear
    O agregar exclusión en Windows Security.

  - El repo en Private para que nadie lo vea.
